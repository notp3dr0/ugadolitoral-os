# Filme do PAÓ · projeto Remotion

- `npm run dev` abre o Remotion Studio (composições Piloto169, Piloto916, Folha).
- `npm run piloto` renderiza o piloto nos dois formatos em `out/`.
- `python -I scripts/sfx.py` regera os efeitos sonoros em `public/sfx/`.

Peças: `src/Pao.tsx` (personagem e controles), `src/Cenario.tsx` (sala, post, balão, botão, asa), `src/anim.ts` (tempo e easing), `src/Piloto.tsx` (os 3 planos).
