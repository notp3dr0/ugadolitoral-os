## Shape Morph · uma forma só, silhuetas, campos de cor, cada morph cai numa palavra

frasco (0,5) → pesquisadora (1,02 "filha") → casa (1,36 "doméstica") → frasco (2,68 "vacina") → coração
(3,38 "salva", corações se multiplicam em "milhões") → pais (5,29) → muda (7,55 "roça") → advogado (8,83) →
documento (9,69 "ajudo") → calendário (10,37 "todos os dias") → ônibus (11,54) → relógio (12,22 "horas") →
bolsista (13,74 "Hoje") → pino de destino (15,18 "transporte") → os três (15,85) → mão (16,36 "Semear") →
seta pra cima (16,98 "empurrãozinho") → pesquisadora (18,8) → semente (19,74 "potencial") → porta (20,78 "faltava")
→ bolsista (22,45) → mão (24,31 "mão") → estrela (24,85 "sonho") → círculo (25,39) → mãos do Semear (26,01 "conquista")
→ preto (26,6) → pessoinhas da copa, a última em 28,0 → assinatura.
Cada morph passa por um círculo, com ~12% de achatamento e leve giro; o campo de cor troca a cada pouso.
